### 🛡️ Featured Project: [ScanMyPrivacy](https://scanmyprivacy.com)

**ScanMyPrivacy** is a free browser-based privacy, leak-testing, and online safety toolkit designed to show what your connection and browser expose—without logging your IP address or storing your inputs.

#### 🔍 What It Does
* **Privacy & Leak Diagnostics:** Runs a weighted **Full Privacy Scan** alongside standalone checks for **DNS leaks**, **WebRTC leaks**, **browser fingerprinting**, **VPN detection**, **open TCP ports**, **HTTP headers**, and **User-Agent / Client Hints**.
* **Online Safety Assistant:** Client-side tools to inspect **suspicious links**, analyze **scam/phishing messages**, audit **mobile app permissions**, and check **website TLS/HTTPS certificates, security headers, and RDAP domain age**.
* **Pre-Consent Cookie & Tracker Scanner:** Audits websites for third-party trackers and cookies loaded before user consent, **Google Consent Mode (`gcs`)** state, first-layer reject options, and **Global Privacy Control (GPC)** compliance.
* **IP & Network Lookups:** Fast **IPv4/IPv6**, **geolocation**, **RDAP**, **DNS**, and **Reverse DNS (PTR)** lookups, backed by a lightweight IP API.

#### 🔒 Privacy-by-Design Architecture
* **Client-Side First:** Fingerprint, WebRTC, link, scam-message, and security checkup analyses run directly in the user's browser with zero server uploads.
* **Zero IP Logging:** Visitor IP addresses are never logged; ephemeral DNS test tokens expire automatically after 10 minutes.
* **Transparent Scoring:** Every check reports clear confidence levels, methodology limits, and exact third-party network calls.
